# 生成运行

某道挑战真正开始生成时，再建 `runs/<挑战>/<run_id>/`：

```text
run_manifest.json
resolved_config.yaml
logs/
raw_outputs/
```

`run_id` 示例：`EGFR_20261106T090000+0800_R01`。挑战目录名使用 `EGFR`、`TNFA`、`GLP1R`。

一次运行固定赛题版本、分子类型、模型版本和主要配置。中断后续跑要写明是从检查点恢复还是新运行。重复输出并入已有候选，不计入新增设计。

原始输出默认不进版本库。清单、配置和日志摘要保留。工具自带示例不放在这个目录。
