# 2026-11-03 三份提交说明的差异

三份材料同一天都能读到，彼此没有完全对齐。生成 scFv 或确定长度之前，先按 `docs/questions-to-organizer.md` 发信。在回复到达前，蛋白和纳米抗体可以按三份材料的交集准备：单链、20 种标准氨基酸、长度 40–250、不加信号肽、不加恒定区、不加标签。

| 项目 | 中文报名页 | 赛题页 FAQ | 平台使用说明 |
|---|---|---|---|
| scFv | `VH:VL`，不加 linker | 必须使用 G4S linker | 单链，VH 与 VL 由 G4S 连接，长度按整条计算；自检推荐 `GGGGS` 重复 |
| IgG1 配对可变区 | `VH:VL`，不加 linker，合计不超过 300 | 只提交 FR 和 CDR，英文冒号分隔，接到人 IgG1 恒定区和 κ 轻链 | 英文冒号分隔，每条链 40–250 |
| 蛋白 / 纳米抗体 | 单链，合计不超过 300 | 单链蛋白长度大于 40 且不超过 250；纳米抗体用 ANARCI 一类工具可注释，并从常见框架开始 | 单链，40–250；纳米抗体为 FR1–CDR3–FR4 |
| 文件列 | 序号、序列名称、序列 | 至少有 name 和 sequence，行序即优先级 | `submission_id`、`AI model`、`name`、`sequence`、`description`。name 不超过 50 字 |
| 条数 | 每个文件恰好 24 条 | 每队 24 条 | 6.4 的表把各分子类型放在同一格，上限写 24 / 账户。说明允许多道题分开提交、分开计数 |
| 提交后 | 修改联系 `poreva_open@megarobo.com` | 主办方在 11 月 19–25 日确认入选序列 | 提交后立即锁定，不能撤回或修改 |
| 表达系统 | HEK293 或无细胞 | 配对 VH/VL 只能哺乳动物。无细胞单链加 C 端 His；哺乳动物单链加 C 端 Fc。标签由实验室添加 | 序列里不要信号肽和恒定区 |

时间以官方竞赛条款为准：北京时间。第一轮提交截止 2026-11-18，平台到点自动关闭。

资格和验证同时受这几句话约束：

- 赛题页：从头设计。不能把已有结合剂当作起点或骨架。抗体和纳米抗体看 CDR 多样性。公开数据可以用来标定、微调和训练。通过资格后按提交记录顺序验证，容量用完后不再验证。每道题计划大约 2,000 条。配对 IgG 不超过该题验证量的 20%。
- 使用说明：是否进入湿实验还取决于设计质量、材料完整程度和总提交量。
- 竞赛条款：合成前做生物安全与序列合规筛查。一队一个账户。

评分、靶点区间和序列见各挑战目录下的 `target_review.md`。页面原文在 `docs/rules/challenges/<挑战>/2026-11-03_page.html`。
