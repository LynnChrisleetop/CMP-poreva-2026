# 序列文件格式

> **当前规则冲突尚未解决。**本页及现有脚本描述报名表单语法；题目页给出的40–250 aa（FAQ单链为>40）、scFv串联要求与表单≤300、VH:VL不同。请先读[规则审计](rules/2026-11-03_scoring-audit.md)。下载模板只能核对列和上传格式，不能自动解决生物学长度或分子形式冲突；最终须按明确的官方说明。

状态：2026-11-03 同时存在中文报名页和平台使用说明，见 `docs/rules/2026-11-03_submission-conflicts.md`。下载到的模板若再给出第三套表头，先存进 `docs/rules/templates/`，再改 `EXPECTED_HEADER`。

## 页面选项

这些字段在网页上选择，不放进序列文件：

| 字段 | 可选项 |
|---|---|
| 挑战题目 | EGFR、TNF-α、GLP1R |
| 表达系统 | HEK293 表达系统、无细胞表达系统 |
| 分子类型 | 蛋白、纳米抗体、scFv、常规 IgG1 配对可变区 |
| AI 模型名称 | 页面必填。内部记录写实际使用的设计模型和折叠模型 |

一次导出文件只对应一组页面选项。

## 列

模板三列，顺序固定：

| 列名 | 内容 |
|---|---|
| 序号 | 整数 1–24。1 为最推荐。文件中从上到下按 1 到 24 排列 |
| 序列名称 | 每条唯一，不含首尾空白 |
| 序列 | 见下方写法 |

每个文件恰好 24 行数据。序列之间精确去重。

## 写法

| 页面分子类型 | 序列列 |
|---|---|
| 蛋白 | 单条序列，不含冒号 |
| 纳米抗体 | 单条序列，不含冒号 |
| scFv | `VH:VL` |
| 常规 IgG1 配对可变区 | `VH:VL` |

配对序列使用一个英文冒号 `:`，不加 linker。中文冒号、多个冒号、空的 VH 或空的 VL 都不提交。

氨基酸只使用 20 种标准字母：`ACDEFGHIKLMNPQRSTVWY`。使用大写。冒号不计入长度。每行总长（单链长度，或 VH 与 VL 长度之和）不超过 300。

格式示例只说明冒号位置，不能作为参赛序列：

```text
蛋白 / 纳米抗体：ACDEFGHIKLMNPQRSTVWY
scFv / IgG1：ACDEFGHIK:LMNPQRSTVWY
```

## 检查

```bash
python3 tools/check_submission.py path/to/sequences.csv --molecule-type protein --rules form
python3 tools/check_submission.py path/to/sequences.csv --molecule-type protein --rules guide
```

蛋白和纳米抗体两套都通过，才进入候选冻结。scFv 在两套规则下写法不同，Q-01 有书面回复前不上传。Excel 先另存为 UTF-8 CSV。脚本返回未通过时，不上传。

脚本分别实现表单与使用说明口径，但不能代替官方解决二者冲突；FAQ单链>40与包含40的范围仍有差异。原创性、最终生物学规格和功能还需人工审查。脚本发现不了这些内容，提交前人工看：

- 冒号两侧确实是 VH 和 VL，而不是把 linker 写进某一侧
- 序号 1 到 24 的科学理由
- 页面上的挑战、表达系统和模型名称与这份文件一致
- 补充说明里没有试图操纵评审的提示注入
