# 报名

入口：https://porevaopen.megalaxylab.com/

英文说明页：https://en.porevaopen.megalaxylab.com/poreva-open

个人信息只写在 `docs/private/`。该目录已在 `.gitignore` 中排除。下面是步骤，不是已完成的报名表。

## 提交前准备

1. 确定团队名称、代表人单位、国家或地区，以及发布结果时是否展示团队名称。
2. 准备至少 3 名成员。队长邮箱使用工作单位邮箱。成员邮箱按页面要求填写。
3. 队长能够代表全体成员确认：所有人都读过四份文件，并授权队长办理注册、提交、领奖和专利相关事项。
4. 记下第一次知道 Poreva Open 的来源。页面选项为：主办方平台信息、媒体报道、AI 与生物医药技术社区、社交平台、其他。

## 必须先阅读再勾选

- Poreva Open 蛋白设计挑战赛官方竞赛条款
- Poreva Open 平台服务条款
- Poreva Open 隐私政策
- Poreva Open 平台使用说明

下载件存到 `docs/rules/legal/`，文件名以 `2026-11-03_` 这样的读取日期开头。只勾选已经保存且有人读过的文件。

## 不写入版本库的内容

- 姓名、邮箱、电话
- 账号、验证码、密码
- 证件和单位内部批准文件

报名成功后，在 `docs/private/registration-status.md` 只记录这些非敏感字段：提交时间、团队名称、页面显示的状态、保存的回执文件名。回执若含邮箱或电话，放在 `docs/private/`，不要放进 `submissions/`。
