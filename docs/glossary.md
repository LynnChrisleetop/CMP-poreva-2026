# 术语

内部用词。官方名称以条款、赛题和报名页为准。

| 术语 | 含义 |
|---|---|
| 挑战 | EGFR、TNF-α、GLP1R。内部目录名分别是 `EGFR`、`TNFA`、`GLP1R` |
| 蛋白 | 报名页分子类型。提交单条序列 |
| 纳米抗体 / VHH | 报名页分子类型。提交单条序列 |
| scFv | 报名页写成 `VH:VL` 且不加 linker。平台使用说明写成含 G4S linker 的单链。两套写法都保留，见提交差异表 |
| IgG1 配对可变区 | 文件里是 `VH:VL`。实验时由主办方接到人 IgG1 恒定区和 κ 轻链，并且只能走 HEK293 |
| HEK293 / 无细胞 | 报名页表达系统。两种系统覆盖哪些检测尚未确认 |
| 恰好 24 条 | 每个序列文件的数据行数。序号 1 是最推荐 |
| 遴选 | 主办方决定哪些设计进入湿实验。补充材料用于这一步 |
| 湿实验 | 鲲鹏实验室按统一流程做的表达和检测。与本地分数分开记录 |
| `proxy_evaluation` | 官方配置尚未齐备时的本地评估。不能称作比赛成绩 |
| `official_aligned` | 已按主办方公布的确切口径复现的评估 |
| `robustness` | 多个种子、多个模型或多种装配下的复核。保留全部结果 |
| ipTM / ipSAE | 报名页举例的设计指标。工具、链方向和阈值未统一前，同名分数不能直接横向比较 |
| 自洽性 | 序列设计与结构预测之间的一致性。具体算法以当次运行记录为准 |
| 成药性评分 | 序列或结构的可开发性估计。它不是热稳定性或非特异结合的实测值 |
| pH 选择性 | 不同 pH 下结合是否改变。数值和方向以赛题原文为准 |
| 细胞功能 | 激活、阻断或其他细胞读出。结合分数不能代替 GLP1R 激活 |
| 家族 | 序列、骨架或界面接近的一组设计。多样性按这三个层面记录 |
| `unconfirmed` | 依赖尚未被官方确认的假设 |
| 提示注入 | 写进提交文本、试图操纵评审模型的指令。报名页写明会被取消资格 |

序列归一化：去掉空白、保留配对序列中的那一个英文冒号，并要求标准氨基酸为大写。出现未知字符时报错，不自动删除或替换。

缺失指标写 `NA` 或留空。不用 0 表示缺失、失败或未测到结合。
