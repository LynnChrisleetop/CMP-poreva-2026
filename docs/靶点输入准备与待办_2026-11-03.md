# Poreva Open：靶点输入包与下一步

更新：2026-11-03。本说明仅适用于 Poreva Open，项目路径为 `/personal/DPcompetition/poreva-open-2026`。

本轮已完成不依赖 GPU 的序列核对、公开参考结构下载、目标残基映射、表达标签排除、原子子集导出、来源归档和独立验收。**5 份目标／物种序列、9 份结构与装配映射、4,561 行逐残基映射已核验。**旧盘点中“无结构／映射”描述的是准备前快照，不再代表当前状态。

## 交付范围

本项目覆盖已公布的 EGFR、TNF-α、GLP-1R 三题，其中 EGFR 和 TNF-α 各含人源与小鼠目标。5 份配置均精确匹配当前归档 UniProt 切片，原有 5 份 FASTA 保持原字节不变。

| 目标 / 物种 | UniProt 闭区间 | 长度 | 主参考 | label 链(auth 链)：有 CA 残基/目标长度 | 参考与当前目标差异（UniProt 编号） |
|---|---|---:|---|---|---|
| EGFR / human | P00533:25–645 | 621 | 6ARU | A(A) 609/621 | N540K、E634R |
| EGFR / mouse | Q01279:25–647 | 623 | AF-Q01279-F1 | A(A) 623/623 | 无当前序列差异 |
| GLP1R / human | P43220:24–432 | 409 | 6X18 | F(R) 384/409 | L260F |
| TNFA / human | P01375:77–233 | 157 | 1TNF | A(A) 152/157；B(B) 152/157；C(C) 152/157 | D219L |
| TNFA / mouse | P06804:80–235 | 156 | 2TNF | A(A) 148/156；B(B) 148/156；C(C) 148/156 | 无当前序列差异 |

“有 CA”只表明该位置存在坐标，不保证侧链完整、构象正确或适合当前设计模型。所有缺失残基都保留在映射表中。参考序列差异来自实际聚合物序列和 ATOM 与当前目标的比较，未直接照抄 PDB 历史突变注释。

## 文件怎么使用

以下路径均相对于 `/personal/DPcompetition/poreva-open-2026`。

```text
targets/<EGFR|TNFA|GLP1R>/
  official_human.fasta             比赛规定范围的目标参考序列
  official_mouse.fasta             仅 EGFR/TNFA 的小鼠目标
  raw/2026-11-03/                  原始 UniProt JSON、完整参考 CIF、assembly1 及元数据
  prepared/2026-11-03/<human|mouse>/
    sequence_review.json          精确序列核验、糖基化/二硫键/结构域等注释
    <ID>.residue_map.tsv           每条目标链 × 每个目标残基的映射
    <ID>.target_observed.cif       已观测目标原子，保留原编号、缺口、构象和差异
    <ID>.summary.json              覆盖率、上下文、糖链、装配、差异及警告
    <ID>_assembly.*                下载的生物装配对应的独立映射和裁切
    manifest.json                 输入输出、配置、工具和依赖版本及 SHA256
    README.md                     该目标/物种的逐结构结果
  prepared/2026-11-03/auxiliary/    EGFR/TNFA 人鼠对应表；鼠 EGFR 预测置信度
configs/target_inputs/             可离线重跑的相对路径配置
tools/prepare_target_inputs.py     CPU 准备工具（10 类合成自测通过）
tools/requirements-target-inputs.txt
docs/target_sources/2026-11-03/     来源审查、标签核对与独立验收
targets/source_manifest_2026-11-03.json
reports/cpu_target_preparation_2026-11-03.json
references/structural_alternatives/TNFA_7JRA/
```

选择结构时，同时查看原始完整装配和目标裁切：`raw` 用于检查糖链、其他蛋白和装配遮挡；`target_observed.cif` 用于目标坐标检查。裁切去除了伴侣、配体、水和糖，不表示这些分子在实验中不存在。`residue_map.tsv` 是编号转换依据；PDB 作者编号、UniProt 编号、官方 FASTA 索引应分别处理。

映射先将完整 UniProt 与沉积聚合物序列比对，再截取目标范围，并独立对照沉积原生区间和实际 ATOM 核验。表达标签采用已核实的 `label_seq_id` 显式排除。这是序列比对与结构核验形成的映射，不声称来自 SIFTS。

2TNF 旧 `struct_ref_seq` 末端存在 155/156 不一致；本包依据实际 156 位实体序列完成映射，未沿用错误的线性端点。人鼠对应表只表示序列位置关系，不证明跨物种结合。

## 已处理与后续建模工作

- **已处理：** 序列、物种和范围核对；表达标签排除；生物装配与非对称单元区分；缺口、实际序列差异、糖链注释及来源追溯。
- **尚未进行：** 缺失环区重建、侧链修复、参考差异回到 WT、质子化、结构优化、糖链补全、复合体预测和设计打分。本轮没有生成参赛候选。
- 后续若设计软件要求连续且完整的坐标，或不接受原作者编号，需要派生新的输入版本并记录映射，保留本包原始证据。
- 结构的覆盖范围不改变比赛目标 FASTA 的定义。建模时如需使用局部片段，应另存配置并说明用途。

## 结构选择的明确限制

1. **人 EGFR：** 6ARU 的 N540K/E634R 保持原样并记录；当前坐标不能称为已修复的 WT 模型。后续预测与复核以目标 FASTA 为准，并审查原始复合物与糖链背景。
2. **人／鼠 TNF：** 保留三聚体。人源 1TNF 的 D219L 是实际残基差异；小鼠 2TNF 的实体序列与目标一致，但仍有缺失坐标。不能由序列一致推断构象或亲和力已经验证。
3. **GLP1R：** 6X18 受体为 auth 链 R、label 链 F，完整装配含激动肽和 G 蛋白等。当前 24–432 WT 参考与 6X18 存在 L260F 差异，且官方称实验试剂含未公开热稳定突变。因此本包可用于研究准备，尚不能认证与实验构建完全一致，也不能据参考结构证明设计具备激动功能。
4. **鼠 EGFR：** 使用明确标记的 AlphaFold DB 预测参考，保存逐残基 pLDDT。模型置信度不等于亲和力；单体预测也不验证糖链、跨物种结合或实际装配。
5. **糖基化：** N-X-S/T 序列位点、UniProt 注释、结构中观察到的糖应分开理解；它们不能直接确认比赛试剂上的实际占位。
6. **补充 TNF 结构：** `references/structural_alternatives/TNFA_7JRA/` 中的 7JRA 与当前目标序列一致，但其小分子配体导致 TNF 三聚体畸变。因此仅作构象敏感性对照，未加入默认设计配置，不能作为无配体 WT 主模板。

## 复现与验收

工具需要 Python 3.10+ 和 Biopython 1.87；本轮实际运行版本见验收记录。这是 CPU 数据准备环境，GPU 设计环境仍需单独部署。重跑必须使用新的输出目录，工具拒绝覆盖非空目录。

在本项目根目录执行：

```bash
python3 -m venv .venv-target-inputs
.venv-target-inputs/bin/python -m pip install -r tools/requirements-target-inputs.txt
.venv-target-inputs/bin/python tools/prepare_target_inputs.py --self-test
```

以人源 TNF 为例，其他目标可替换配置文件和新输出路径：

```bash
.venv-target-inputs/bin/python tools/prepare_target_inputs.py \
  --config configs/target_inputs/TNFA_human.json \
  --out targets/TNFA/prepared/recheck_new_run/human
```

验收覆盖：完整目标长度与区间、每个目标残基逐行存在、作者编号与插入码、源 ATOM 残基类型、标签排除、派生坐标逐原子保持原值，以及配置和输入输出哈希。9 份最终映射共 4,561 行，均通过独立复核。通过这些检查不等于通过比赛评分或完成特定模型的输入适配。
